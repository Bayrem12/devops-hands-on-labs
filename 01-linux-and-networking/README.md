## Essential Commands

```bash
pwd                 # Current directory
ls -la              # List all files
cd /path            # Change directory
cp source dest      # Copy
mv source dest      # Move or rename
rm file             # Remove a file
mkdir directory     # Create directory
cat file            # Display file contents
grep "text" file    # Search inside a file
find /path -name "*.log"  # Find files
df -h               # Disk space
free -h             # Memory usage
```

## Linux in DevOps

- Manage servers and application environments.
- Automate repetitive tasks with shell scripts.
- Configure networking and system services.
- Deploy and troubleshoot applications.
- Work with containers and cloud infrastructure.

**Remember:** Linux is the operating environment behind much of modern infrastructure.
