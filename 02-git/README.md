# Git & Version Control

Git is a distributed version control system used to track changes, manage code history, and collaborate on software projects.

## Topics Covered

| Topic | What it helps with |
|---|---|
| Git Fundamentals | Track changes and create commits |
| Remote Repositories | Synchronize local and remote repositories |
| Branching | Work on separate features |
| Merge & Rebase | Integrate changes from different branches |
| Cherry-pick | Apply a specific commit |
| Revert & Reset | Undo changes safely or move repository history |
| Stash | Temporarily save unfinished work |

## Quick Workflow

```bash
git status
git add .
git commit -m "Describe the changes"
git push
```

Git is more than saving files. It provides a structured history of changes and tools to manage collaboration, experimentation, and recovery.
